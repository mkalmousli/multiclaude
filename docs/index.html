Frequently asked questions

Can I use two Claude Code accounts at once?

Yes. Each mcl instance sets its own CLAUDE_CONFIG_DIR, so you can run different logins in different terminals simultaneously.

How do I switch Claude Code accounts without logging out?

Create an instance per account with mcl new work, then start it with mcl work. Each one keeps its own login, so there is nothing to switch.

Does mcl share settings between accounts?

Only if you ask. mcl new name --share links settings.json, CLAUDE.md, commands, agents and skills from ~/.claude. Logins and history always stay separate.

Where does mcl store my data?

In ~/.multiclaude/<name> by default. Set MULTICLAUDE_HOME to change it.

Is mcl free?

Yes, fully free and open source under the MIT license.

Which platforms are supported?

Linux, macOS and Windows with Python 3.9 or newer.

Is mcl affiliated with Anthropic?

No. It is an independent open-source tool that launches the official claude CLI.
